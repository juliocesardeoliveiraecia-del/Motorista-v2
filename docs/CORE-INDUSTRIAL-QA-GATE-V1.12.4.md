# Doctor Core QA Gate V1.12.4

Release remains blocked until question content is reviewed, traceability is populated, central catalog is seeded by Main, integrations are homologated, and desktop/mobile end-to-end tests pass.

The quality gate now checks simulated exam count, subject distribution, answer key range, unique question IDs, and content duplicates independent of question ID and answer key. These structural checks do not prove factual correctness; independent editorial review remains mandatory.
